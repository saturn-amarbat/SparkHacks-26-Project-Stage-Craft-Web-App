## Inspiration
Our team was discussing how an AI model can be used in a shopping scenario, and we used the movie theme of SparkHacks 2026 to inspire what the shopping website would promote. One of the members also added how difficult it is to find certain cosplays for niche characters and how this website can solve that problem
## What it does
This website can narrow down the catalog of items using the built-in AI tool and find the most significant listing for the user!
## How we built it
We split the tasks of building the project amongst the three members: Front-end and _UX_, Back-end and AI logic, and Managing Data with _SQL_
## Challenges we ran into
The AI model used **heavy** resources for each prompt. We solved this by using the cache and a connected database to reuse previously generated answers so as to not repeat the same executions, along with a few constant prompts that produce constant answers
## Accomplishments that we're proud of
A working AI model implementation that **efficiently** searches our catalog for the item a customer is thinking about. Smooth page transitions, clean presentation of products, and a polished marketspace
## What we learned
We learned how to implement an AI model within a website and how to code and stylize a structured website
## What's next for StageCraft
Our next step for StageCraft is to bring in affiliate sponsors to post their products on our website and populate it with a more diversified catalog!
